# أرشيف صوتي شخصي — تفريغ بالعامية المصرية ومناقشته

ترمي تسجيلاتك → تتفرّغ نصًا بالعامية المصرية → تناقشها وتستخرج منها أنماطًا.
يعمل من أي متصفح أو موبايل، بلا تثبيت أي شيء على أي جهاز.

---

## الطريقة الأسرع للبدء

**١.** أنشئ مستودعًا **خاصًا (Private)** على GitHub وارفع فيه هذه الملفات.

> مستودع خاص، لا عام. هذه تسجيلات حياتك — لا تضعها في مكان مفتوح.

**٢.** جهّز مفتاحًا (تخطَّ هذه الخطوة لو ستستخدم الوضع `local`):

`Settings` → `Secrets and variables` → `Actions` → `New repository secret`

| الاسم | من أين | التكلفة |
|---|---|---|
| `GEMINI_API_KEY` | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | مجاني |
| `GROQ_API_KEY` | [console.groq.com/keys](https://console.groq.com/keys) | مجاني |
| `ELEVENLABS_API_KEY` | [elevenlabs.io](https://elevenlabs.io/app/settings/api-keys) | مدفوع |

**٣.** فرّغ أول تسجيل:

ارفع التسجيل على Google Drive من زر المشاركة في موبايلك، واجعله
"أي شخص لديه الرابط"، وانسخ الرابط. ثم في المستودع:

`Actions` → **1) تفريغ تسجيل** → `Run workflow` → الصق الرابط → اختر المحرك → `Run`.

بعد دقائق يظهر التفريغ في مجلد `journal/`، وملخّص النتيجة في صفحة التشغيل نفسها.

**٤.** ناقش تسجيلاتك:

`Actions` → **2) ناقش الأرشيف** → اكتب سؤالك → الرد يظهر في نفس الصفحة
ويُحفظ في `answers/`.

مثال أسئلة:
- إيه المواضيع اللي بترجع لها كل شهر؟
- إيه اللي اتغير في طريقة كلامي عن شغلي بين أول تسجيل وآخر واحد؟
- فين المرات اللي قلت فيها إني هعمل حاجة وما عملتهاش؟

## اختيار المحرك — الخصوصية أهم من الدقة هنا

| المحرك | الدقة على العامية | التكلفة | صوتك يخرج لمين؟ |
|---|---|---|---|
| `local` | جيدة | **صفر** | **لا يخرج لأي شركة ذكاء اصطناعي** |
| `gemini` | ممتازة (يفهم السياق) | مجاني | Google — **والطبقة المجانية تُستخدم في تحسين منتجاتهم** |
| `groq` | متوسطة إلى جيدة | مجاني | Groq |
| `elevenlabs` | الأعلى (١٣٫١٪ WER على المصري) | مدفوع | ElevenLabs |

### تنبيه لازم تقراه قبل ما تختار

شروط Gemini API تنصّ صراحةً أن محتوى **الطبقة المجانية** قد يُقرأ بواسطة
مراجعين بشريين ويُستخدم في تطوير منتجات Google. الطبقة **المدفوعة** لا
تُستخدم في التدريب. نفس المنطق ينطبق على معظم الطبقات المجانية عند المزودين.

تسجيلاتك هنا ليست ملفات عمل — هي كلامك عن نفسك. فأمامك ثلاثة مسارات صادقة:

1. **مجاني وخاص:** استخدم `local`. Whisper يعمل على سيرفر GitHub، وصوتك لا
   يُرسل لأي مزود ذكاء اصطناعي. أبطأ (ساعة صوت ≈ ٢٥–٤٠ دقيقة معالجة) لكن
   لا يهم — أنت لست منتظرًا أمام الشاشة.
2. **رخيص وخاص:** اربط الفوترة في Google (تصير طبقة مدفوعة = لا تدريب).
   التكلفة الفعلية لتفريغ ساعة صوت بـ Gemini 2.5 Flash حوالي **١٠ سنتات**.
   هذا أفضل توازن بين الدقة والخصوصية.
3. **مجاني وسريع مع تنازل:** استخدم `gemini` المجاني، وخُذ في حسابك أن
   المحتوى قد يُراجَع. مناسب للمكالمات العادية والاجتماعات، لا لأكثر
   تسجيلاتك خصوصية.

للمناقشة (`ask.py`) نفس الكلام ينطبق: الأسئلة والتفريغات تُرسل لـ Gemini.

## لماذا هذا الحل يفرّغ ملفات كبيرة مجانًا

المزودون المجانيون يضعون حدًا للحجم (Groq مثلًا ٢٥ ميجا). الحل ليس دفع المال،
بل التعامل مع الصوت بشكل صحيح:

**١. ضغط ذكي.** كل محركات التعرف على الكلام تُخفّض الصوت داخليًا إلى
16kHz أحادي القناة. فتحويل الملف لهذه الصيغة مسبقًا (Opus 24kbps) لا يُفقد
دقة التفريغ إطلاقًا، لكنه يقلّص الحجم بشدة.

قياس فعلي على هذا المشروع:

```
23.9 MB  →  6.4 MB     على ملف اختبار مُصنَّع
المخرَج الموثوق: ~11–12 MB لكل ساعة صوت
```

نسبة التوفير تتبع جودة تسجيلك الأصلي، فلا تُعوّل عليها. الرقم الثابت هو
المخرَج: **~١١–١٢ ميجا لكل ساعة** أيًّا كان المصدر. فتسجيل ساعتين يصير
~٢٥ ميجا، وثلاث ساعات ~٣٦ ميجا.

**٢. القطع عند الصمت لا عند زمن ثابت.** القطع في منتصف كلمة هو السبب الأول
لأخطاء التفريغ. السكربت يكشف فترات الصمت أولًا ثم يقطع عند أقربها للهدف.

**٣. تمرير السياق بين المقاطع.** كل مقطع يُرسَل مع آخر ما قيل في المقطع
السابق، فلا ينقطع تسلسل الكلام عند الحدود.

**٤. prompt يمنع "الترجمة" للفصحى.** أشهر فشل في تفريغ العامية المصرية أن
الموديل يحوّل «مش عارف أعمل إيه» إلى «لا أعرف ما أفعل» فتضيع نبرتك. الـ prompt
يمنع ذلك صراحةً ويطلب النقل الحرفي.

## المخرجات

لكل تسجيل أربعة ملفات في `journal/`:

| الملف | الاستخدام |
|---|---|
| `.md` | للقراءة — طوابع زمنية وأسماء متحدثين |
| `.txt` | نص متصل بلا طوابع |
| `.srt` | للاستماع مع متابعة النص |
| `.json` | للبحث والتحليل — وهو ما يقرأه `ask.py` |

## التشغيل على جهازك (اختياري)

```bash
pip install -r requirements.txt
winget install --id Gyan.FFmpeg -e     # ويندوز
cp .env.example .env                   # واملأ المفتاح

python transcribe.py "C:\path\call.m4a" --speakers 2
python transcribe.py "C:\path\folder"   # كل الملفات في مجلد
python ask.py --interactive             # محادثة مستمرة مع أرشيفك
```

خيارات مفيدة:

| الخيار | الوظيفة |
|---|---|
| `--speakers 2` | مكالمة — يميّز المتحدثين |
| `--hints "منى,أحمد,شركة كذا"` | يضبط رسم الأسماء |
| `--provider local` | بلا مفتاح وبلا تكلفة |
| `--since 2026-01-01` | (في `ask.py`) يحدّ الفترة |

## الحدود التي يجب معرفتها

- **وظيفة GitHub Actions الواحدة:** ٦ ساعات كحد أقصى. تكفي لتفريغ عدة ساعات صوت.
- **الحساب المجاني:** ٢٠٠٠ دقيقة تشغيل شهريًا للمستودعات الخاصة.
  الوضع `local` يستهلك منها بكثافة؛ مسار الـ API يستهلك دقائق قليلة جدًا.
- **رفع الملفات عبر متصفح GitHub:** ٢٥ ميجا فقط. لهذا مسار الرابط
  (`audio_url`) هو الطريق الموصى به للملفات الكبيرة.
- **مجلد `inbox`:** أي ملف تدفعه إليه يُفرّغ تلقائيًا ثم يُحذف — لكن يبقى في
  تاريخ Git للأبد ويكبّر المستودع. فضّل مسار الرابط.
- **Gemini المجاني:** ٢٥٠ طلبًا يوميًا لـ 2.5 Flash — أي عشرات الساعات يوميًا.

مفيد فعلًا. لكنها ليست معالجًا نفسيًا ولا تُشخّص. لو ظهر في تسجيلاتك ما يُقلقك
